# 대장간 강화소

브라우저에서 바로 하는 검 강화 게임. 파일 하나(`index.html`)로 돌아가요.

- **대장간**: 검(+80까지)과 곡괭이(+35까지) 강화
- **광산**: 돌을 캐서 골드·보석·룬석, 광부 고용, 보석 합성
- **사냥터 9곳**: 조이스틱으로 움직이며 자동 공격, 사냥터마다 보스
- **보스 던전**: 보스 9마리 연전 (최종 목표)
- **여정과 장인 등급**: 19단계 목표, 특성 4종
- 캐릭터 8종, 스킬 11종, 상점, 친구, 효과음과 배경음악

## 실행
`index.html`을 브라우저로 열면 돼요. 진행 상황은 그 브라우저에 저장돼요.
claude.ai 아티팩트로 열면 계정 저장과 친구 기능도 쓸 수 있어요.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (HTML·CSS·JavaScript) |
| `patch-notes.html` | 버전별 업데이트 기록, 현재 규칙과 수치, 조정용 변수 목록 |

수치를 바꾸려면 `patch-notes.html`의 **조정용 변수** 목록에서 이름을 찾아 `index.html`에서 고치면 돼요.
